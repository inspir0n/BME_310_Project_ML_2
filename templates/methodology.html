Methodology

What was implemented, how this replication differs from Kufel et al. (2023), and observations from the reproduction process.

1.

Exactly what we're doing

WHAT?
An EfficientNet-B1 backbone, fine-tuned end-to-end, with a custom classification head producing 14 independent probability outputs — one for each finding.
WHY?
A chest X-ray can show multiple conditions at once. Softmax forces classes into a single competing probability distribution, whereas sigmoid allows each finding to be evaluated independently.
HOW?
ImageNet-pretrained weights fine-tuned with discriminative learning rates and cosine scheduling using a patient-wise split designed to reduce data leakage, along with augmentation to control overfitting.
PROOF?
Per-label AUC, AUPRC, sensitivity/specificity on a held-out test set — plus Grad-CAM, to evaluate whether the model focuses on clinically relevant image regions rather than irrelevant features.
2.

Architecture

An EfficientNet-B1 backbone, pretrained on ImageNet, with its own 1000-way head removed and replaced with:

Global average pool → Dropout → Dense(512) → BatchNorm → ReLU → Dropout → Dense(256) → ReLU → Dense(14)

The backbone is fine-tuned end-to-end using discriminative learning rates, with a lower learning rate for pretrained layers and a higher learning rate for newly initialized classifier layers.

3.

Deviations from the paper, and why

Area Paper This replication
Validation set Original paper reports training and evaluation statistics, but the exact validation protocol is not fully described. Three-way patient-level split: 70% train / 10% validation / 20% test
Split seed 2137 (reported seed; selection rationale not described) Scanned 300 seeds for the one with the most balanced rare-label distribution
Input resolution Never stated 240×240 — EfficientNet-B1's own design resolution
Dropout Not specified in the paper 0.3, twice in the head — the first run overfit sharply by epoch 3 without it
Learning rate Not explicitly reported Discriminative rates + cosine decay, added specifically to fix that overfitting
Augmentation H-flip p=0.3, rotate ±5° p=0.1, brightness ±0.2 Stronger: flip p=0.5, affine scale/translate/rotate p=0.7, brightness+contrast p=0.8
4.

Observed inconsistencies during reproduction

Checking the paper's own numbers against the raw data surfaced several small errors:

  • Unique patients: reported as 32,717 — the actual NIH figure is 30,805. The reported number of unique patients differs from the commonly cited NIH ChestX-ray14 statistics.
  • Baltruschat et al.'s average AUC is listed as 0.727 in the paper's comparison table; their own 14 per-label values actually average to 0.806.
  • Parameter counts: EfficientNet-B1 vs DenseNet-121 given as "6.7M vs 8.4M" — measured values are closer to 6.5M and 8.0M.
  • The conclusion states binary cross-entropy "strengthens underrepresented classes." Standard BCE alone does not explicitly address class imbalance.
5.

Honest limitations

  • Rare labels are noisy. Hernia has only 227 positive cases in the entire 112,120-image dataset — around 46 land in the test split. An AUC computed from that few positives has real statistical uncertainty.
  • ROC-AUC alone may not fully represent practical performance under severe class imbalance. See the Results page for AUPRC and precision alongside AUC.
  • Grad-CAM surfaced a real anomaly. Grad-CAM visualizations provide interpretability but may still highlight regions that require expert review.
  • Domain shift. Thresholds and performance are calibrated on this specific dataset's scanners and population. Expect a real accuracy drop on X-rays from a different hospital.
