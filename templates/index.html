What this is

The problem, the data, and what was actually built.

The NIH ChestX-ray14 dataset contains 112,120 frontal chest radiographs from 30,805 patients, with each image labelled for up to 14 thoracic findings derived from radiology reports. This project reproduces a 2023 paper's multi-label classification approach: an ImageNet-pretrained EfficientNet-B1 backbone fine-tuned with a lightweight classifier head, producing one independent sigmoid output for each finding.

This is a course project developed to reproduce and evaluate the paper's methodology, including analysis of implementation differences and model performance. The methodology page covers what deviates from the paper and why, and discusses the differences between the original methodology and this implementation.

PyTorch EfficientNet-B1 Patient-wise split Grad-CAM Transfer Learning Multi-label Classification Flask

This model is a student replication project and is not intended as a medical device. The live demo is designed to explore model behavior and predictions, not to provide diagnosis or clinical decisions.
